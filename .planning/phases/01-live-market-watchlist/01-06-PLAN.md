## User Story

**As a** beginner, **I want to** open FinAlly and watch real or simulated prices stream into my watchlist, **so that** I can see the market moving and know whether the data is real.

This plan lets the beginner shape their own watchlist. Adding a ticker starts it streaming, removing one stops it, and both survive a restart.

<objective>
This plan exposes the watchlist REST API from PLAN.md section 8 (GET, POST, DELETE) on top of the SQLite watchlist:
- One ticker rule: upper-case, then `^[A-Z]{1,5}(\.[A-Z])?$` (D-10).
- LIVE-mode existence check through `source.check_ticker` (D-11), while SIMULATED mode accepts any well-formed symbol (D-12).
- Immediate start and stop of tracking through one reconciler (D-13).
- Rowid ordering (D-21).
- Removals that stay removed across restarts (DB-02, D-02).

Purpose: success criterion 5 says "User can add a valid ticker (it starts streaming), sees invalid symbols rejected with a clear message, and can remove a ticker. A removed default ticker does not come back after a restart." Plan 01-08 adds the UI for it.
Output: `tickers.py`, the db watchlist writes, `services/tracking.py`, `services/watchlist.py`, `routes/watchlist.py`, main.py wiring, and tests.
</objective>
