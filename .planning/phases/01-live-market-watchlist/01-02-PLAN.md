## User Story

**As a** beginner, **I want to** open FinAlly and watch real or simulated prices stream into my watchlist, **so that** I can see the market moving and know whether the data is real.

This plan delivers the backend half of "know whether the data is real": every stream event and `/api/health` say which source is active, why, and whether its prices are fresh.

<objective>
This plan completes the frozen D-03 envelope by adding `status: {source, stale, note}`. It adds per-source freshness tracking with the D-15 thresholds and the D-04 startup probe, which picks LIVE only on a real OK and otherwise falls back to the simulator with a plain-language reason that never contains the key. It extends `/api/health` (D-05) through the same status builder. It also adds `check_ticker`, which plan 01-06 uses for D-11 and D-12.

Purpose: honest data labelling (DATA-01, DATA-02, DATA-04, DATA-08) is the backend contract behind the header badge built in plan 01-07.
Output: `status.py`, probe and fallback in `massive.py` and `factory.py`, source attributes, the stream status, the health route, and tests.
</objective>
