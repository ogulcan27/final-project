## User Story

**As a** beginner, **I want to** open FinAlly and watch real or simulated prices stream into my watchlist, **so that** I can see the market moving and know whether the data is real.

This plan completes the slice. The beginner adds and removes tickers from the screen, and one command proves the whole phase in the real container.

<objective>
This plan puts the watchlist API from plan 01-06 on screen:
- An add form with a purple submit button (WATCH-03, D-10, D-11, D-12 messages from the server).
- A hover remove x on each row (WATCH-04, D-18).
- Rows in REST order (D-21), with immediate streaming after an add (D-13).
It closes the phase with a container gate (OPS-01) that exercises fallback honesty (D-04, D-05), add, remove and persistence (D-02) against the real Docker image.

Purpose: success criterion 5 says "User can add a valid ticker (it starts streaming), sees invalid symbols rejected with a clear message, and can remove a ticker. A removed default ticker does not come back after a restart." All five success criteria are then checked once in the container.
Output: `api.ts` and tests, store `tickers`, the `AddTicker` component, the row remove control, and `backend/scripts/container_gate.sh`.
</objective>

9. No key in the logs: docker logs "$NAME" (stdout and stderr) must not contain FAKE_KEY.
