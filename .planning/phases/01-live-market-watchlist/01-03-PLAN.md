## User Story

**As a** beginner, **I want to** open FinAlly and watch real or simulated prices stream into my watchlist, **so that** I can see the market moving and know whether the data is real.

This plan makes the skeleton runnable with one Docker command and keeps user data and secrets out of git.

<objective>
This plan ships the single-container deployment (OPS-01, PLAN.md section 11, with the research deviation node:24-slim) and protects persisted data (D-01, D-02, D-07):
- A user_version guard refuses the stale `finally-data` volume schema.
- Seed-once and schema tests are added.
- .gitignore rules cover DB files, and a committed .env.example documents the variables (DB-05).
- A smoke script proves the container serves the page, the API and the stream on the 8020 test port.

Purpose: success criterion 1 says "from a fresh checkout ... building and running the Docker image ... SQLite file is created automatically and git ignores it".
Output: the guard plus tests, ignore rules, `.env.example`, `db/.gitkeep`, `.dockerignore`, `Dockerfile`, `backend/scripts/smoke.py`, and concise README updates.
</objective>
