## User Story

**As a** beginner, **I want to** open FinAlly and watch real or simulated prices stream into my watchlist, **so that** I can see the market moving and know whether the data is real.

This plan turns the skeleton page into the Bloomberg-style terminal grid, with a real watchlist fed by one shared stream store.

<objective>
This plan builds the full terminal grid now, so later phases fill panels instead of reshuffling the layout (D-09). It applies the UI-01 dark theme with Tailwind 4 CSS-first tokens. It moves stream handling into a zustand store plus one hook, and renders watchlist rows with ticker, price and Day % (WATCH-01, the D-18 columns).

Purpose: success criterion 1 asks for a "dark terminal-style layout" with live prices. Later plans add flash and sparkline (01-05), header status (01-07) and add/remove (01-08) on top of these components.
Output: the theme, Panel, the grid page, types, the store, the hook, the Watchlist and WatchlistRow components, and tested format helpers.
</objective>

1. frontend/src/shared/types.ts mirrors the frozen D-03 envelope, using the field names from PriceUpdate.to_dict:
   - export type PriceUpdate with ticker string, price number, previous_price number, prev_close number, change_pct number, direction "up" | "down" | "flat", timestamp number.
   - export type MarketStatus with source "live" | "simulated", stale boolean, note string or null.
   - export type PriceEnvelope with prices (a PriceUpdate array) and status (a MarketStatus).
   - export type ConnectionState = "connected" | "reconnecting" | "disconnected".
   Shared code lives in src/shared/, never src/lib/ (gitignored, Pitfall 1).

2. frontend/src/store/prices.ts exports usePriceStore, built with zustand 5 create typed as PriceStore (the curried create-then-call form).
   - State: prices (a record from ticker to PriceUpdate, initially empty); order (string array of tickers in envelope order, initially empty); status (MarketStatus or null, null until the first envelope); connection (ConnectionState, initially "reconnecting").
   - Action setEnvelope(env): replaces prices with a record built from env.prices, sets order to the envelope's tickers in order, and sets status to env.status.
   - Action setConnection(c).
   - Selector rule (Pattern 10): components select only primitives or stored references, such as the price for one ticker or the order array itself. A selector that builds a new object or array re-renders forever under useSyncExternalStore.

3. frontend/src/hooks/usePriceStream.ts exports usePriceStream().
   - One useEffect creates new EventSource("/api/stream/prices").
   - onopen calls setConnection("connected"); onerror calls setConnection("reconnecting") (D-17; plan 01-07 adds the red timeout and CLOSED recovery); onmessage calls setEnvelope(JSON.parse(event.data)).
   - The cleanup closes the EventSource.
   - Read the actions via usePriceStore.getState() inside the handlers.
